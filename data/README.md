# Pasta `data/` — Descontinuada

> **A partir da v1.0, toda a informação do site está em `/content`.**

Esta pasta existia na arquitetura anterior. Os arquivos JSON legados foram removidos na Release Candidate.

Use exclusivamente:

- `content/eventos.json`
- `content/musicas.json`
- `content/videos.json`
- etc.

Consulte o [README principal](../README.md) para instruções de edição.
