## v1.0 — 7 de agosto de 2026

**Release Candidate — Publicação**

### Portal

- ✓ Portal Oficial completo
- ✓ Hero Premium (Ken Burns, partículas, animações suaves)
- ✓ Microinterações nos cards
- ✓ Skeleton loading com fade
- ✓ Transições entre páginas
- ✓ Barra de progresso de scroll
- ✓ Botão voltar ao topo

### Conteúdo

- ✓ Memoriais dinâmicos (template único)
- ✓ Agenda automática (futuro vs. realizado)
- ✓ Discografia e videografia
- ✓ Timeline narrativa do ministério
- ✓ Mapa do Brasil interativo
- ✓ Testemunhos
- ✓ Galeria Dourados (30 fotos curadas)

### Plataforma

- ✓ Busca global
- ✓ Favoritos (memoriais salvos)
- ✓ Compartilhamento social
- ✓ Modo TV
- ✓ PWA (manifest + service worker)
- ✓ Analytics local (admin)

### Qualidade

- ✓ SEO completo (Schema.org, sitemap, OG, Twitter)
- ✓ Acessibilidade (skip link, ARIA, contraste, teclado)
- ✓ Lightbox profissional (contador, zoom, swipe, teclado)
- ✓ Segurança (CSP, headers, HTTPS-ready)
- ✓ Deploy: Netlify, Cloudflare Pages, Vercel
- ✓ Safe Area (iPhone notch / Dynamic Island)

### Arquitetura

- ✓ CMS-ready via `/content` (JSON)
- ✓ Camada de serviços (`/services`)
- ✓ JavaScript modular (< 300 linhas por arquivo)
